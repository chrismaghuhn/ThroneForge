# Security policy

ThroneForge is an early architecture-only project. No runtime package loader, game adapter, code-mod loader, or network service is available yet.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when enabled. If it is unavailable, contact the repository owner through GitHub before public disclosure and include only the minimum reproduction details needed for triage.

## Scope

Security-sensitive areas planned for later milestones include archive extraction, package validation, profile transactions, data-only graph execution, support-bundle redaction, and explicit full-trust code-mod approval. Thronefall binaries and assets are intentionally outside this repository.
